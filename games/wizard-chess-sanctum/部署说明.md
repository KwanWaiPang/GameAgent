# 巫师棋 · The Sanctum — 部署与操作说明

这是一个独立制作的哥特风格 3D 巫师国际象棋网页游戏。项目为**单个 `index.html`**，无需 Node.js、npm 或打包构建。

## 本次修复：8 × 8 棋盘格

已修复原版棋盘格被金色底板遮挡的问题：抬高 64 个棋盘格，采用深浅双色石砖，并增加细窄的暗色格线。棋子定位、点击选格与移动逻辑保持不变。

## 一、Github Pages 部署

1. 在 GitHub 上创建一个公开仓库，例如 `wizard-chess`。
2. 将 `index.html` 上传至仓库根目录。
3. 打开仓库 `Settings` → `Pages`。
4. `Build and deployment` 中将 `Source` 改为 `Deploy from a branch`。
5. 选择 `main` 分支、`/(root)` 路径，点击保存。
6. 发布后，访问 `https://你的用户名.github.io/wizard-chess/`。

如果习惯命令行，在本文件所在目录打开终端：

```bash
git init
git add .
git commit -m "Add 3D wizard chess game"
git branch -M main
git remote add origin git@github.com:你的用户名/wizard-chess.git
git push -u origin main
```

已经有仓库的情况下，不要重复执行 `git init` 或 `git remote add origin`，把文件复制到仓库根目录并提交推送即可。

## 二、本地运行

进入项目文件夹后，执行：

```bash
python -m http.server 8000
```

在浏览器打开 `http://localhost:8000/`。

项目使用 CDN 引入 Three.js 和 chess.js，**首次打开需要正常访问 jsDelivr**。因浏览器 ES Module 安全限制，推荐用本地服务器打开，而不是直接双击 HTML。

## 三、游戏操作

- 鼠标左键：选择棋子、点击高亮格落子
- 鼠标左键拖动：旋转场景
- 鼠标滚轮：缩放视角
- 鼠标右键拖动：平移视角
- `New Game`：重新选择 AI/双人、先后手和难度
- `Undo`：悔棋（AI 对战中通常回退双方各一步）
- `Camera` / `Top View` / `Reset View`：切换视角
- `Flip`：换边观看
- `H`：隐藏/显示 UI；`U`：悔棋

支持标准国际象棋规则：王车易位、吃过路兵、兵升变、将军、将死、逼和和常见和棋判定。

## 四、说明

- 本项目为参考巫师棋玩法与哥特视觉风格的**独立实现**，未直接使用参考网站的专有棋子模型、贴图或程序源码。
- 棋子、建筑、光效均由 Three.js 几何体和材质程序化生成；并非 Blender 原版精细角色资源，因此无法逐帧复现参考网站。
- AI 基于简易搜索，不是 Stockfish；`ARCHMAGE` 模式也不代表大师级棋力。
- 网页已完成 JS 语法静态检查，但由于当前执行环境无法连接 CDN，未完成真实浏览器端的图形渲染测试；发布后请在 Chrome/Edge 中检查运行情况。
